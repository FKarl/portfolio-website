# Fabian Karl: Portfolio Website

Source code for [fkarl.de](https://www.fkarl.de), built with Next.js (static export) and next-themes.

## Sections

Hero · Research (AIdapt) · Publications · About · Side projects · Contact

All text lives in `lib/i18n.ts`, once in the `en` block and once in the `de` block. Profile links (email, CV, Scholar, GitHub, ...) are in the `LINKS` object at the bottom of the same file.

## Maintenance guide

### Publications

The list is loaded from DBLP's public SPARQL endpoint (`sparql.dblp.org`), in two places:

- **At build time**: `scripts/update-dblp-snapshot.mjs` runs before every `npm run build`. It saves the current list to `lib/dblp-snapshot.json`, which is baked into the HTML so search engines see the papers, and regenerates `public/llms.txt`. If DBLP is unreachable, the existing snapshot is kept.
- **In the browser**: `components/publications.tsx` queries the same endpoint on page load and replaces the snapshot with the live result.

Nothing needs updating by hand when a new paper appears on DBLP; rebuilding the site refreshes the snapshot.

- **Paper missing from DBLP**: add it to the `MANUAL` array in `components/publications.tsx`.
- **Duplicates**: an arXiv preprint is hidden when a published version with the same title exists.
- **Types**: DBLP has no workshop flag, so a paper counts as a workshop paper when its venue contains `@` or "workshop".

### Current project and research themes

`lib/i18n.ts` → `research` (both languages): label, title, lead, body, the fact list and the three theme cards. The project page URL is `LINKS.aidapt`. The project mark is in `public/assets/aidapt/` (light and dark variants).

### About and timeline

`lib/i18n.ts` → `about` (both languages). Add a new entry at the top of `timeline` when you start a position or finish a degree.

### Side projects

`lib/i18n.ts` → `projects.items` (both languages): `title`, `body`, `linkLabel`, `href`.

### Photos

- `public/assets/hero/portrait.jpg`: hero portrait, cropped to 4:5 by CSS (`.hero-photo`).
- `public/assets/hero/about.jpg`: About photo, cropped to a square by CSS (`.about-photo`). Adjust `object-position` in `app/globals.css` if a new photo is framed differently.

### CV file

Replace `public/resources/CV_Fabian_Karl.pdf`. The path is `LINKS.cv` in `lib/i18n.ts`.

### SEO and sharing

- Page title, description and structured data: `app/layout.tsx`.
- Share-card image: `public/og.png` (1200×630). Replace it if the headline or portrait changes.
- `public/llms.txt` is generated by the snapshot script; edit its text in `scripts/update-dblp-snapshot.mjs`.
- `public/sitemap.xml`: update `lastmod` after larger changes.

### Colours and dark mode

Colour tokens for both themes are at the top of `app/globals.css`. The theme follows the visitor's system setting until they use the toggle in the header.
